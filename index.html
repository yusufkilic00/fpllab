EVENT TYPE FILTERSChoose what the matchup should measure

Counts use selected gameweeks and keep each event family separate. “Headers” are header-shot body-part events, not aerial duels. Final-third passes are successful passes ending in the attacking third. For conceded actions, attacking left maps to defensive right (and vice versa), assuming attack-normalized feed coordinates. Reverse feed orientation with “Flip width direction” above when needed.

CROSSES & HEADERS

Delivery and aerial finishing context.

SELECTED GWS

Crosses and header shots are counted independently from the Opta event feed. Completed crosses use the event outcome flag. Header shots use the header body-part qualifier. The imported schema does not expose a verified event-to-event relation, so FPL LAB does not claim that a particular header came from a particular cross.
